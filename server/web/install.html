📱 Handy – einfachster Weg (30 Sekunden)

  1. Diese Seite im Handy-Browser öffnen: …

📺 Fernseher (Google TV / Android TV / Fire TV)

Wird geprüft …

Weg A – mit der App „Downloader“ (kein USB-Stick nötig):

  1. Am Fernseher im Play Store nach Downloader suchen (blaues Symbol, von AFTVnews) und installieren
  2. Fernseher-Einstellungen → System → Info → 7-mal auf Build/Android-Version klicken → Entwickleroptionen sind jetzt frei
  3. Einstellungen → Apps → Sicherheit & Einschränkungen → Unbekannte Quellen → Downloader einschalten
  4. Downloader öffnen und diese Adresse eintippen:
    …
  5. Go drücken → die Datei lädt → Installieren → Öffnen
  6. In der App die Server-Adresse von oben eintragen → fertig
Der Download klappt, aber das Installieren nicht?
Das ist fast immer derselbe Grund: Auf dem Fernseher liegt noch eine ältere GHGFlix-Fassung, die Android nicht überschreiben will (etwa weil die neue Datei mit einem anderen Schlüssel unterschrieben ist oder eine kleinere Versionsnummer hat). Android sagt dann nur „App nicht installiert“ und nennt keinen Grund.

Lösung – alte Fassung zuerst entfernen:
  1. Fernseher-Einstellungen → Apps → Alle Apps anzeigen
  2. GHGFlix auswählen → Deinstallieren
  3. Im Downloader dieselbe Adresse noch einmal aufrufen → jetzt läuft die Installation durch
Deine Bibliothek, Fortschritte und Favoriten liegen auf dem Server, nicht in der App — beim Deinstallieren geht davon nichts verloren. Nur die Server-Adresse musst du danach einmal neu eintragen (oder den QR-Code zum Koppeln benutzen).

Weg B – mit USB-Stick:

  1. APK jetzt herunterladen (am PC)
  2. Datei auf einen FAT32-USB-Stick kopieren
  3. Unbekannte Quellen erlauben (siehe Weg A, Schritt 2 + 3 – dort statt Downloader deinen Datei-Manager freigeben)
  4. Am Fernseher einen Datei-Manager installieren (z. B. X-plore oder File Commander aus dem Play Store)
  5. Stick einstecken → Datei-Manager → GHGFlix.apk → Installieren
Es liegt noch keine App-Datei (APK) auf dem Server. Ohne die geht der Weg über „Downloader“ oder USB-Stick nicht.

So kommt die APK auf den Server (einmalig, am PC):

  1. Kostenloses Konto auf expo.dev anlegen
  2. In PowerShell:
    cd "$env:USERPROFILE\Documents\GHGFlix\mobile"
    npm install
    npx eas-cli build --platform android --profile preview
  3. Am Ende bekommst du einen Download-Link → die .apk herunterladen
  4. Die Datei in den Server-Ordner legen und in GHGFlix.apk umbenennen:
    /DATA/AppData/ghgflix/data/apk/GHGFlix.apk
    (in ZimaOS über Files – der Ordner apk muss ggf. angelegt werden)
  5. Diese Seite neu laden – die Anleitung oben erscheint dann automatisch

Der Ordner liegt im Daten-Verzeichnis und überlebt jedes Server-Update. Du legst die Datei also genau einmal ab.

Weg C – ganz ohne Installation:

Am Fernseher den Browser öffnen und … eingeben. Der TV-Modus (große Schrift, Pfeiltasten-Steuerung, roter Auswahlrahmen) startet automatisch.
